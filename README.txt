LOCAL LIBRARY — готовый учебный проект Django

Требования:
- Python 3.10 или новее
- Django 5.2.19

УСТАНОВКА В WINDOWS (команды выполняются из папки LocalLibrary_ready):

1. Создайте виртуальное окружение:
   py -3.10 -m venv venv

2. Активируйте:
   venv\Scripts\activate

3. Установите зависимости:
   pip install -r requirements.txt

4. Создайте таблицы базы данных:
   py manage.py migrate

5. Создайте администратора:
   py manage.py createsuperuser

6. Запустите сайт:
   py manage.py runserver

Откройте:
- Главная: http://127.0.0.1:8000/
- Каталог книг: http://127.0.0.1:8000/books/
- Авторы: http://127.0.0.1:8000/authors/
- Админ-панель: http://127.0.0.1:8000/admin/

Добавление данных:
1. Войдите в /admin/.
2. Сначала добавьте жанры и авторов.
3. Затем добавьте книги.
4. Для каждой физической копии книги создайте Book instance.

ВАЖНО:
Если вы переносите проект в уже существующую папку, сохраните копию старой папки.
Виртуальное окружение venv в архив не включено — его нужно создать на компьютере.
Файл базы данных db.sqlite3 тоже не включён: он создастся после команды migrate.
